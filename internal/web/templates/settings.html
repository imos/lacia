クライアントIDの作り方

  1. 連携するアカウントで Google Cloud の「認証情報」を開きます。
  2. プロジェクトで Google Calendar API を有効にします。
  3. 「OAuth クライアント ID」の種類に「ウェブ アプリケーション」を選んで作成します。
  4. 「承認済みのリダイレクト URI」に、次のアドレスを登録します。
    {{.Redirect}}
  5. 表示されたクライアントIDとクライアントシークレットを、上の欄に入力して「Googleで許可する」を押します。

入力したシークレットと、連携に必要な認証情報は、サーバーでGitの管理外に保存します。保存した値を画面やログに表示することはありません。
