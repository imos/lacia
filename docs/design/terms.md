# 言葉の使い分け

`lacia` の文書とコードで、似た意味に聞こえる言葉を、次のように使い分けます。新しく書くときは、この表に合わせてください。

| 言葉 | コードや設定での対応 | 意味 |
| --- | --- | --- |
| プロファイル | 起動時の `--profile` | サーバー1つ分の設定です。設定ファイルの `[work]` のような節が、1つのプロファイルです。`lacia serve --profile <名前>` で選びます |
| 相手 | 設定の `peer` | 伝言と引き継ぎの相手にするプロファイルです |
| プロファイルの呼び名 | 設定の `label` | 画面や伝言でプロファイルをどう呼ぶかを決めます。「仕事モード」など、それぞれの環境で使う名前を指定します |
| 場所 | 会話の `place` | 会話の名前の前半です。サーバーはプロファイル名を、接続する端末は登録時の場所の名前を使います。名前を指定しない会話の場所は `local` です。ローカル環境で `lacia serve` を起動する構成でも `local` を使います |
| サーバー | `web.Server` | 記録と Web の画面を受け持つ `lacia serve` の役割です。ローカル環境でも別の環境でも使います |
| 登録した端末 | 実行先の `device` | サーバーの外で会話を起動するための端末です。たとえば、`lacia agent` で別のサーバーから予約を受ける端末です |
| ログイン | 会話の `login` | Codex や Claude Code の、アカウントの使い分けです。プロファイルとは別のものです |
| オーナーさん | 呼び名の設定 `user` | 記録のリポジトリーの持ち主を指す役割名です。ご本人の呼び名は `LACIA_USER`、記録の `.lacia/config.json` の `user` の順に探します。どちらもなければ「オーナーさん」と呼びます |
| ほかの方 | 設定の `people` | オーナーさんのほかにレイシアが話す方々を、まとめて指す言葉です。「ご家族」などを設定できます。個々の方には、その方の呼び名を使います |
| タスクの担当 | タスクの `owner` | タスクを進めている会話の名前です。どのセッションが担当しているかは `owner_session` に記録します |
| 予約、定期タスク | `schedules/`、Web の `/routines` | 決まった時刻や間隔で繰り返す仕事を「予約」と呼びます。Web の一覧や詳細を案内するときは、画面の名前「定期タスク」を使います |
| 申し送り | `handover.Handover` | `lacia tell` で別の会話に届ける依頼や、待っていた処理が終わったあとにすることです。受け手は `lacia wait ack` で受け取りを知らせます。サーバーが受け取った会話を特定できると、その会話をタスクの担当にします |
| プロファイル間の引き継ぎ | `lacia handoff` | チャットの側から、オーナーさんがすることや決めることをタスクの側へ渡します |

## 組になった2つのプロファイル

伝言と引き継ぎをやり取りする2つのプロファイルには、それぞれ役割があります。コードのコメントでは、次のように呼び分けます。

| 言葉 | 役割 |
| --- | --- |
| タスクの側（the task side） | タスクと Web の画面を持つ側です。相手へ伝言を送り、引き継ぎを受け取ります |
| チャットの側（the chat side） | チャットで人と話す側です。タスクを持ちません。伝言を受け取り（設定の `inbox`）、オーナーさんにしていただくことを引き継ぎます |

「仕事モード」「家庭モード」のような名前は、使う人が呼び名として決めるものです。1台で使う場合も、別の環境で動かす場合も、役割と権限は設定で決まります。`lacia` のコードと文書では、例として出すときのほかは、使いません。

## 使わない言葉

| 使わない言葉 | 代わりに使う言葉 |
| --- | --- |
| モード（mode）、ドメイン（domain） | 仕組みを指すときは「プロファイル」と書きます。画面や文面で指すときは、そのプロファイルに付けた呼び名を使います |
| home、work（プロファイルの意味で） | チャットの側、タスクの側、相手 |
| Codex のアカウントを指す「プロファイル」「side」 | アカウントの使い分けは「ログイン」と書きます。`codex --profile` などの引数や、設定のキー `side` はそのまま書きます |
