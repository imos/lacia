# 旧予約から固定IDへ移したときの記録

形式1の記録で、`schedules/<名前>.md` の予約を固定IDへ移すときに使った手順です。現行の定期タスクは、固定IDがある形式で管理します。

以前の形の控えを扱う場合は、[当時の手順](https://github.com/imos/lacia/blob/0963cc1d037620dfab774294f78c3c51b91f8d31/docs/design/routine-migration.md)と、[同じ版の移行スクリプト](https://github.com/imos/lacia/blob/0963cc1d037620dfab774294f78c3c51b91f8d31/scripts/migrate-routines.py)を使います。記録と実行状態の控えを作り、仮のコピーで確かめてから移します。

すでに固定IDがある形式1の定期タスクは、[記録の形式2への移行](https://github.com/imos/lacia/blob/1570490e1d8c669f4dd026e08df37963eaf71d59/docs/design/records.md#形を移すlacia-migrate)の手順で、IDを保ったまま領域の下へ移せます。
